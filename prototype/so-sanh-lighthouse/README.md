# So sánh hai cách sửa cho Lighthouse

Cả hai file là Căn phòng gốc, chỉ khác nhau ở điểm sau:

- `cach-2-title-meta.html`: đổi title thành “FocuSpace — Căn phòng học Lo-fi” và thêm meta description.
- `cach-1-title-meta-lofi-sau-click.html`: như cách 2, và chỉ bắt đầu dựng 6 bài nhạc Lo-fi sau cú nhấp hoặc phím đầu tiên (bản gốc dựng ngay khi mở trang).

Cách đo: mở từng file trong Chrome → DevTools → Lighthouse → Mobile → Analyze, so điểm Performance, SEO và Total Blocking Time.
